# 🚀 My Personal Portfolio

Welcome to my personal portfolio repository! This is a modern, fully responsive, and SEO-optimized web application designed to showcase my journey, technical skills, projects, and professional experience as a Software Engineer.

🧑‍💻 **Live Demo:** https://akshaybhawar03.github.io/portfolio/
---

## 🌟 Features

* **⚡ High Performance:** Built on top of **Vite** for blazing-fast bundling and performance.
* **🎨 Modern UI/UX:** Styled beautifully with **Tailwind CSS** featuring fluid animations and a clean layout.
* **📈 SEO Refactored:** Optimized with comprehensive meta tags, semantic HTML, and structure for search engines.
* **📱 Fully Responsive:** Seamless experience across mobile, tablet, and desktop viewports.
* **🤖 Automated Deployment:** Integrated with **GitHub Actions** for continuous deployment (`npm ci` and automated build pipelines).

## 📁 Repository Structure

```text
├── .github/workflows/  # GitHub Actions Deployment CI/CD
├── public/             # Static assets (images, icons, etc.)
├── src/                # Main application source code
│   ├── components/     # Reusable UI Components
│   └── main.js         # Core logic
├── index.html          # Application entry point (SEO optimized)
├── tailwind.config.js  # Tailwind CSS configuration
```
